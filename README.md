# minishell

Yet another shell.
Because apparently bash and fish weren't enough.

Unix-like shell written in C. Still a basic project.

## Build & Run

```sh
make
./shell
```

For debugging:

```sh
make debug
```
Can handle:
- n number of pipes 
- output redirection

Current Limitations:
- Arguments must be seperated by spaces
- Parsing is still pretty basic
